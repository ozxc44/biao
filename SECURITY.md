# Security policy

## Supported versions

Security fixes are made against the current `main` branch. If you use an
older revision, first check whether the issue is reproducible on current
`main`.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Submit a
private GitHub security advisory instead:

https://github.com/ozxc44/biao/security/advisories/new

Include affected versions, reproduction steps, impact, and any safe proposed
mitigation. Maintainers will acknowledge the report, coordinate remediation,
and publish disclosure details after a fix is available.
