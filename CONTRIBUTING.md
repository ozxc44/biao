# Contributing to Biao

Thanks for contributing.

## Before opening a pull request

- Keep changes focused and include tests for changed behavior.
- Do not commit `.biao/`, `.codex/`, `.env*`, tokens, local databases, task
  evidence, or other runtime data.
- Run the relevant checks from the project README. For a complete change, run
  `npm test`, `npm run test:web`, `npm run build`, and `npm run verify:package`.
- Describe behavior changes, migration impact, and validation evidence in the
  pull request.

## Contribution terms

## Security issues

Do not disclose vulnerabilities in public issues. Follow
[SECURITY.md](SECURITY.md) instead.
